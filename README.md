# Solar Statistik

HACS integration. After install, **Solar** is a sidebar app in the Companion app. No YAML.

**Repo:** https://github.com/fromWaterToWind/solaranlage-statistik

## Install

1. HACS → Integrations → Custom repositories → `https://github.com/fromWaterToWind/solaranlage-statistik` → category **Integration**
2. Download **Solar Statistik**
3. Restart Home Assistant
4. Settings → Devices & services → Add integration → **Solar Statistik**

Tariff (from–to) is in the app under ⚙.

## iOS app (Capacitor)

Standalone iPhone build with Keychain-backed Growatt token. See [ios/README.md](ios/README.md).
